## 怎么回答一项技术问题

一个高质量的技术回答至少包含：问题为何存在、关键计算或系统过程、对应的资源与统计代价、如何进行对照验证。下面的问题适合用于模型研究和工程面试的深度追问。

## 1. Self-Attention 为什么通常是平方复杂度

标准密集 Attention 需要计算所有 Query 与 Key 的两两打分。若序列长度为 N，矩阵 QKᵀ 具有 N×N 项；在隐藏维度固定的常见讨论下，其计算随 N² 增长。

注意“计算复杂度”和“额外显存”是两个指标。FlashAttention 可以减少中间矩阵的访存与保存，但不会凭空取消两两打分的计算。

## 2. 为什么需要缩放因子 √dₖ

在一定独立、同方差近似下，dₖ 维随机点积的方差与 dₖ 相关。用 √dₖ 归一化分数尺度，有助于避免 Softmax 过早进入极端饱和。

要说明这是一个统计直觉，不是任何数据分布下都严格成立的恒等式。

## 3. 为什么 Decode 经常是带宽受限

每轮生成一个新 Token，但必须读取历史 KV Cache 参与注意力。矩阵计算并行性相对较低，内存读写占比较高。

讨论优化时区分 TTFT、TPOT、batch 调度、KV 压缩和量化，避免用一个 tokens/s 数字概括所有服务性能。

## 4. GQA 与 MLA 都减少 KV，但原理一样吗

不一样。GQA 让多个 Query 头共享较少的 KV 头；MLA 将 K/V 信息压缩到潜变量，并结合矩阵吸收等技巧实现推理计算。

比较需要明确缓存维度、位置编码和实际内核形式，不能只看理论头数比例。

## 5. LoRA 的秩 r 应如何确定

低秩增量的参数量为 r(d_in+d_out)，所以秩越大容量和训练成本通常越高。应在相同数据、计算预算和评估协议下扫描多个秩，比较任务效果和峰值显存。

也要考虑 target_modules 和训练目标；它们可能比单独改变秩更重要。

## 6. RAG 的回答错了，排查顺序是什么

先看原始文档能否提供正确证据，再看召回候选是否命中，随后看重排和上下文是否保留正确证据，最后看生成模型是否忠实使用证据。

这种顺序对应不同的可干预组件，有助于避免反复调整 Prompt 而忽略检索错误。

## 7. Recall@k 与 nDCG@k 区别是什么

Recall@k 衡量相关文档有多少进入前 k；nDCG@k 同时考虑相关性等级和排序位置。只需要召回至少一条关键证据时，可以考虑 Hit@k，但不要把它等同于多证据召回。

## 8. Agent 为什么需要执行器和状态机

大模型产生动作建议，执行器负责参数验证、权限、预算和工具调用。状态机让中间结果、错误恢复和退出条件具备确定语义。

是否完成任务应由外部检查条件决定，例如测试通过或数据已写入，而不是由模型单方面声明。

## 9. DPO 与 PPO/RLHF 的区别在哪

DPO 以偏好对构造直接训练目标；PPO 使用策略比、优势估计等进行策略优化，常涉及奖励模型反馈。两者从优化数据和交互方式上存在重要差异。

比较时需要固定评测集和输出长度等变量，而不是仅用训练代码复杂度评价。

## 10. 怎么证明一项算法改进确实有效

明确独立样本单位、训练/测试隔离、强基线和预先定义的主要指标。用消融实验识别关键机制，使用正确的配对比较和分层分析解释结果。

不同随机种子的重复训练可以说明优化稳定性，但不能替代独立测试样本的统计证据。

## 把深问整理成可推导的回答卡片

每个问题都可以固定四个字段：问题约束、关键计算、资源或统计代价、验证方式。例如对于 KV Cache：

| 字段 | 应回答的内容 |
|---|---|
| 问题约束 | 自回归生成会重复投影历史 Token |
| 关键机制 | 保存每层历史 K/V，仅追加新位置 |
| 资源代价 | 缓存字节数随长度、KV 头数和层数增长 |
| 验证方法 | 比较缓存/不缓存路径的 Logits 与 TPOT |

这种模板不是为了把所有答案写成四句口号，而是检查回答有没有遗漏关键论证环节。如果问题偏数学，就把“验证方式”替换成数值实验或边界条件分析。

## 两个有辨识度的追问

**追问 A：GQA 为什么不等于直接把 KV Cache 除以四？**

需要先固定 Query 头数、KV 头数、Head 维度、精度和模型层数。理论上，32 个 KV 头改为 8 个时，主要缓存张量是原来的四分之一；但运行时还有权重、内核工作区与缓存管理开销，因此整机显存不会精确变成四分之一。

**追问 B：为什么一次训练十个随机种子不等于十个独立测试集？**

多个随机种子可以反映训练初始化与数据顺序的波动。如果评估始终使用同一批测试对象，它们并没有自动产生新的独立观测对象。对于同一对象贡献多个窗口的任务，还应按对象层级设计测试和不确定性估计。

面试时把两种不确定性分清楚，能够展示对实验统计单位与模型优化过程的真实理解。
